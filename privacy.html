Historical Xiaxia GPT Action Privacy Policy

Historical / outdated notice: This page describes the retired Custom GPT Action integration. Xiaxia's current entry point is ordinary ChatGPT → Plugin → MCP. This document has not been updated to describe current Plugin/MCP data processing and should not be treated as the current privacy notice.

Last updated: August 2026

Overview

Xiaxia GPT Action is a personal AI assistant application created for private use.

This privacy policy explains how Xiaxia GPT Action handles information when users connect external services.

Google Calendar Access

Xiaxia GPT Action uses Google Calendar API to access calendar information only after the user explicitly grants authorization through Google's OAuth authentication system.

The application uses Google Calendar data only to provide calendar-related assistance, such as viewing upcoming events and helping users organize their schedules.

Xiaxia GPT Action does not access Google Calendar information without user permission.

Information Usage

Calendar information accessed through Google Calendar API is used only to provide personalized assistant functions requested by the user.

The application does not sell, transfer, or share users' calendar data with third parties.

Data Storage and Security

Xiaxia GPT Action does not independently store users' Google Calendar data.

Access to Google Calendar is managed through Google's OAuth authentication system. Users can revoke access permissions at any time through their Google Account settings.

Third Party Services

Xiaxia GPT Action uses Google Calendar API provided by Google LLC. Users' use of Google services is also subject to Google's own privacy policies and terms.
